# Tasks

Verification conventions: Python suites run with `python3 -m unittest discover -s <dir> -p '<pattern>'`. The Node launcher suite runs with `node --test routing-editor/tests/test_editor_launcher.mjs`, and frontend tests with `npm --prefix routing-editor test`. All configuration and installation tests use temporary roots, `--global-config-dir`, and `CLAUDE_ROOT`/`CODEX_ROOT`/`WINDSURF_MEMORIES_ROOT` (or the PowerShell parameters). Never use the real agent directories or `~/.clanker`. Full-suite runs and editor builds are requested before running, per repository rules. Preserve the pre-existing unrelated edits to `README.md`, `routing-editor/scripts/editor.mjs` and `routing-editor/tests/test_editor_launcher.mjs`.
